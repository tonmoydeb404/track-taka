# App icons

Generated, not hand made. The source is the brand tile
`public/brand/mark.svg`; `src/app/icon.svg` is a generated copy of it (Next.js
serves that path via its metadata file convention), and `icon-maskable.svg` is
the same mark on a full-bleed square with the glyph scaled into the maskable
safe zone (inner ~80%).

To regenerate after a design change (needs Homebrew `rsvg-convert` or
ImageMagick):

```sh
npm run sync-brand        # version + every file below from public/brand/mark.svg
npm run sync-brand:check  # CI check: exits 1 when outputs are stale
```

The script renders `icon-192.png`, `icon-512.png`, `apple-touch-icon.png` and
`icon-maskable-512.png` from the SVGs, copies the tile to `icon.svg` paths,
and packs `src/app/favicon.ico` (16/32/48) in pure Node. It also builds
`icon-maskable.svg` (full-bleed tile, glyph scaled into the safe zone),
refreshes the lockups in `public/brand/`, and swaps the inline mark in
`public/offline.html` (the fallback page must stay self-contained).

`src/app/manifest.ts` and the root layout metadata point at these files.

## Brand lockups

`public/brand/` holds the horizontal logo (`logo.svg` for light surfaces,
`logo-dark.svg` for dark ones) and the standalone tile `mark.svg` — the tile
is the hand-made source; the lockups are regenerated by `npm run sync-brand`
from it. The wordmark is
"Track Taka" set in Manrope Bold, converted to outlines so the files need no
font; its path data is preserved verbatim and only the embedded mark is
swapped. The mark is a 3×3 field of entries with a route stepping up through them
and an amber marker on today, on the brand blue `#0a7fc4` (`src/lib/brand.ts`).
